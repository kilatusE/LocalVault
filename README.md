# LocalVault

**完全オフライン・高セキュリティ Android パスワード管理アプリ**

通信機能を一切持たず（`INTERNET` 権限ゼロ）、すべてのパスワードを端末内に暗号化して安全に保管します。Android 標準の自動入力サービス（`AutofillService`）に対応し、Chrome などのブラウザや各種アプリ上で自動入力と未登録パスワードの保存確認を行えます。

---

## 主な機能

- **完全オフライン設計（Zero-Network）**
  - `INTERNET` / `ACCESS_NETWORK_STATE` / `ACCESS_WIFI_STATE` などの通信権限をマニフェストから強制排除。
  - OS標準のクラウド自動バックアップ（`allowBackup`）を無効化。
- **多層暗号化と生体認証**
  - 2層鍵構造（KEK / DEK）：マスターパスワードから **PBKDF2WithHmacSHA256（600,000回反復）** で鍵を導出し、**AES-256-GCM** ＋ **SQLCipher** でデータベースと機密フィールドを暗号化。
  - **Android Keystore + `BiometricPrompt.CryptoObject`** によるハードウェア連携の生体認証ロック解除（生体情報の追加・変更時は鍵を自動失効）。
- **Googleパスワードマネージャー風の自動入力 & 未登録時の保存確認**
  - Chrome などのブラウザや各アプリでドメイン・パッケージ名を照合し、キーボード上部チップ（Android 11+ インライン候補）およびドロップダウンで自動入力。
  - 未登録サイトでログインすると Android 標準の **「LocalVault にパスワードを保存しますか？」** ダイアログを自動表示。
- **パスワード使いまわし警告 & セキュリティ診断**
  - 登録・編集時のリアルタイム重複警告、保管庫一覧の警告バー・重複バッジ、詳細画面での重複先サイト名表示、セキュリティスコア診断。
- **強力なパスワード作成**
  - 暗号学的乱数（`SecureRandom`）で安全なパスワードを自動作成。文字数ドロップダウン・文字種設定は「作成」タブと「新規登録・編集」画面で自動同期。
- **ローカル暗号化バックアップ / 復元**
  - 機種変更に備え、端末ローカルへ暗号化バックアップファイル（`.lvault`）を書き出し・復元可能。
- **プライバシー保護 & カスタマイズ**
  - 全画面でスクリーンショット・画面録画を禁止（`FLAG_SECURE`）、バックグラウンド時の自動ロック、クリップボード自動消去（Android 13+ 機密フラグ対応）、パスワード入力欄での予測変換無効化。
  - **ダーク / ライトモード切替**、端末内アプリの本物アイコン自動取得（完全オフライン）＆ **サイトカラー / モノクロ切替**。

## 動作要件

- Android 8.0 (API 26) 以上（ターゲット SDK 35 / Android 15）
- ビルド環境: JDK 17、Android SDK (API 35)

## ビルド方法

```bash
./gradlew assembleDebug
```

リリースビルド（R8 難読化・リソース圧縮有効）:

```bash
./gradlew assembleRelease
```

## 使い方（自動入力の有効化）

1. アプリを起動してマスターパスワードを設定します。
2. ホーム画面のバナーまたは「設定 ＞ 自動入力 ＞ 自動入力サービスの設定」から **LocalVault** を選択します。
3. Chrome やアプリでログインすると、未登録パスワードの保存確認や次回以降の自動入力が動作します。
